# 🪲 Scarab Index

A curated, TypeScript-backed index of resources (websites, portals,
databases, books, journals) for studying Egyptology — split by level:
**beginner**, **intermediate**, **expert**.

> Like a scarab, this index is meant to dig up and surface what's worth reading.

## TL;DR — how to update the live site

This repo is set up with **GitHub Actions → GitHub Pages** (Settings → Pages →
Source: "GitHub Actions"). The only thing you ever need to do is:

1. Edit `src/data/resources.ts` (add/change a resource)
2. ```bash
   git add -A
   git commit -m "add resource X"
   git push
   ```

That's it. GitHub builds and republishes the site automatically — check the
**Actions** tab for a green checkmark (~30–60s). Live at:

**https://bbmane.github.io/scarab-index/**

You do **not** need to run `npm run build` locally, and you do **not** need
to touch `docs/index.html` by hand — it's regenerated by the build.

## Why

Instead of a static markdown list, resources are typed data (`src/types.ts`),
so they can be filtered, searched and — later — exposed via CLI, API or a web
app without rewriting anything.

## Structure

```
src/
  types.ts            Resource type definition
  data/resources.ts    the actual resources
  query.ts             filter/search helpers (byLevel, search, ...)
  cli.ts               small terminal CLI (scarab)
  index.ts             library entry point (export *)
docs/
  index.html           self-contained web app (generated, see below)
scripts/
  web-template.html    the web app's HTML/CSS/JS shell (edit this)
  build-web.mjs         injects resources into the template → docs/index.html
```

## Web app

`docs/index.html` is a single self-contained page with the resources,
browsable with search and level filters — no server, data is embedded
directly in the page.

**`src/data/resources.ts` is the single source of truth.** `docs/index.html`
is *generated*, not hand-edited: `npm run build` compiles the TypeScript and
then injects the resulting data into `scripts/web-template.html`, producing
`docs/index.html`. So:

- Add/edit a resource → only touch `src/data/resources.ts` (see the TL;DR at
  the top — just commit and push, GitHub Actions does the rest).
- To change the page's look, layout or behavior → edit `scripts/web-template.html`,
  then push the same way.

Want to preview a change before pushing? Run `npm run build` locally and open
`docs/index.html` by double-clicking it.

### How the automatic deploy works

`.github/workflows/deploy.yml` runs on every push to `main`: installs
dependencies, runs `npm run build` (TypeScript → `dist/`, then
`dist/data/resources.js` → injected into `scripts/web-template.html` →
`docs/index.html`), and deploys `docs/` to GitHub Pages. This requires
**Settings → Pages → Source: "GitHub Actions"** (already set for this repo).

## Usage

```bash
npm install
npm run build

node dist/cli.js list                      # all resources
node dist/cli.js level expert               # filter by level
node dist/cli.js maps                       # only resources with interactive maps/timelines
node dist/cli.js search "tomb"              # free-text search
```

Once installed as a package, the same commands are available via the `scarab` bin:

```bash
scarab list
scarab level beginner
```

During development, without building:

```bash
npm run dev -- list
```

## Adding a resource

Add an object to `src/data/resources.ts` matching the `Resource` interface in
`src/types.ts`. `id` must be unique and kebab-case.
